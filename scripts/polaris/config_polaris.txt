Configuracion de Polaris
-obtener el token de root
curl.exe -X POST "http://127.0.0.1:8181/api/catalog/v1/oauth/tokens" -u "root:secrete" -H "Content-Type: application/x-www-form-urlencoded" -d "grant_type=client_credentials" -d "scope=PRINCIPAL_ROLE:ALL"
-comprobar que el token funciona
curl.exe -X GET "http://127.0.0.1:8181/api/management/v1/catalogs" -H "Authorization: Bearer TU_TOKEN"

curl.exe -X POST "http://127.0.0.1:8181/api/management/v1/catalogs" -H "Authorization: Bearer TU_TOKEN" -H "Content-Type: application/json" --data-binary "@config\polaris\insurance_catalog.json"
